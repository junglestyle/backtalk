# Coding standards

backtalk follows the [org standards](org-standards.md) and the standards for its topics
([python](org-standards-python.md)), unchanged copies of
[junglestyle's](https://github.com/junglestyle/.github/tree/main/code-standards). `.org-standards` lists the topics it
copies beyond the general one. This file adds backtalk's own rules and examples. Where it differs from an org rule, it
says so, and it wins.

## Known deviations

Where backtalk doesn't follow the org standards yet. These are debt to pay down, not overrides: each one should go.

- There's no `docs/SPEC.md` or `docs/ROADMAP.md` yet (see [Docs](org-standards.md#docs)).
